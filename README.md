# Arslan Alisher — Portfolio

**Live site:** https://cod3xc.github.io/iwamad-sis1-portfolio/

This is my personal portfolio website. It has three sections: About Me, Projects and Contact. It works on phones and computers and has a dark mode.

## Design decisions
1. **Layout:** On a computer, the projects are in three columns so I can see them all at once. On a phone, they go into one column because three columns would be too small to read.
2. **Colours:** I chose one purple-blue colour for buttons and links so the page looks simple and consistent. In dark mode I made the background dark blue and the text light, so it is easy on the eyes. Both themes use the same colour names, so the whole page changes with one click.
3. **After phone testing:** I tested the page at 375 px and changed the About Me section. The photo and text now sit one under the other on a phone instead of side by side. I also made the buttons and text big enough to read and tap.
